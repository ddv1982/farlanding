# 0003 — Binary assets in plain git; editor MCP addon vendored

Date: 2026-11-12

## Binary assets

Exported models, textures and audio in `game/assets/` are committed as plain
git objects, not Git LFS.

- Every asset is generated by a script in `art/` or `audio_src/`, so history
  can always be rebuilt and files stay small (the largest is under 2 MB).
- git-lfs is not installed on the development machine or assumed in CI.
- A fresh clone must run without a build step, so outputs are committed.

Revisit if the repository passes roughly 500 MB or a single asset passes 20 MB.
The LFS rules are kept, commented out, in `.gitattributes`.

## Godot editor MCP addon

`game/addons/godot_mcp/` and the `MCPRuntimeProbe` autoload are vendored so
the editor can be driven by AI tooling (scene authoring, play-testing,
screenshots). The probe does nothing outside an editor debug session, and the
addon is excluded from lint, formatting and script warnings like every addon.
